# Banking Management System (C++)

## Overview

This project is a console-based Banking Management System developed in C++ to apply Object-Oriented Programming (OOP) concepts and Standard Template Library (STL) containers.

## Features

* Create New Account
* Delete Existing Account
* Deposit Money
* Withdraw Money
* Check Account Balance
* Transfer Funds Between Accounts
* Display All Accounts
* View Transaction History

## Concepts Used

### Object-Oriented Programming

* Classes and Objects
* Constructors
* Encapsulation
* Friend Functions
* Operator Overloading

### Standard Template Library (STL)

* map
* vector
* Iterators

## Technologies

* C++
* OOP
* STL
